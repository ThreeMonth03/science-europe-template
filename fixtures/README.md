# Public test fixtures

This repository owns the two public English and Traditional Chinese Common DSW
Knowledge Model 2.7.0 snapshots in `knowledge-models/`. `make knowledge-models`
verifies their fixed SHA256 without downloading files or requiring the Tool
repository. Snapshot provenance and attribution are recorded next to the bundles.

The bundles are tracked test inputs. Missing files or a wrong hash are rejected,
not silently fetched or replaced. No real project answers or credentials are used.
Current answer matrices are generated by the retained test helpers.

Historical multi-round pilot exports are available in Git history, not maintained
as a second current answer corpus. Narrowly retained event fixtures used by
current semantic regressions are synthetic test input rather than DMPs or
evidence that every questionnaire branch has been reviewed.
