# Public test fixtures

`make knowledge-models` downloads the public English and Traditional Chinese
Common DSW Knowledge Model 2.7.0 bundles into `knowledge-models/` and verifies
their SHA256. The exact fixture-data commit and expected hashes live in
`scripts/prepare_knowledge_models.py`; that data pin is independent of the
build Tool version in the Chinese pipeline.

The bundles are cached locally and ignored by Git. Existing bytes with a wrong
hash are rejected, not replaced. No real project answers or credentials are
used. Current answer matrices are generated by the retained test helpers.

Historical multi-round pilot exports are available in Git history, not maintained
as a second current answer corpus. Narrowly retained event fixtures used by
current semantic regressions are synthetic test input rather than DMPs or
evidence that every questionnaire branch has been reviewed.
